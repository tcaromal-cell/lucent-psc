WDTech Coaching starter website
================================

Included:
- index.html: responsive one-page website
- Sample quick quiz with automatic scoring
- Demonstration 10-minute timer
- YouTube and Instagram links

IMPORTANT
- This is a starter website. The sample quiz and timer work in the browser.
- Study material cards are placeholders; add your real PDF/Drive links.
- The demo timer is not yet a full exam engine. It does not store scores, student accounts, rankings, or results on a server.
- No custom domain or hosting has been purchased or configured.

How to preview:
1. Extract the ZIP.
2. Open index.html in a web browser.

Free publishing option:
Use GitHub Pages (requires a free GitHub account):
1. Create a new public repository named wdtech-coaching.
2. Upload index.html to the repository root.
3. Open repository Settings -> Pages.
4. Choose deploy from branch, select main and /(root), then Save.
5. GitHub will provide a public website address after deployment.

You can also publish through a free static-hosting service. Before public launch, check the site on mobile and replace all placeholder study materials with actual links.
