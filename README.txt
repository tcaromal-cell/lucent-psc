HOW TO UPDATE YOUR GITHUB WEBSITE FROM ANDROID
1. Open your GitHub repository: https://github.com/tcaromal-cell/lucent-psc
2. Open the repository's file list.
3. Delete the old index.html or open it and replace its contents with the new index.html from this ZIP.
   Easiest method on a phone: download/extract this ZIP, then upload the new index.html to the repository. If GitHub asks whether to replace the existing file, confirm and commit the change.
4. Keep the repository on the main branch and GitHub Pages configured to deploy from the main branch / root folder.
5. Wait a minute or two, then visit: https://tcaromal-cell.github.io/lucent-psc/

The website uses no build tools, paid hosting, or external libraries. It links to the Lucent PSC YouTube channel: https://www.youtube.com/@lucentpsc

Note: The included quiz is a small sample quiz, not a complete PSC mock-test system. You can add more questions later.

Update: Added an Instagram link (https://www.instagram.com/lucent_psc/) and a YouTube feature card on the home page. The YouTube card links to the channel videos page so visitors can see the current thumbnails.
