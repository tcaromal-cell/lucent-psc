LUCENT PSC WEBSITE — HOMEPAGE UPGRADE

This package updates the existing LUCENT PSC GitHub Pages website.
It is not a new repository and does not require a hosting change.

FILES
- index.html: complete replacement homepage

BEFORE UPLOADING
- Keep a copy of your current index.html as a backup.

PUBLISH ON GITHUB (Android or desktop)
1. Open https://github.com/tcaromal-cell/lucent-psc
2. Open the repository's root folder (the page showing index.html).
3. Open index.html and choose the pencil/Edit option, or use Add file > Upload files.
4. Replace the existing root index.html with this package's index.html.
5. Commit the changes to the main branch.
6. Wait a minute or two, then refresh https://tcaromal-cell.github.io/lucent-psc/

IMPORTANT
- Upload index.html itself, not this ZIP file.
- The file must remain in the repository root, not inside a nested folder.
- Do not delete or change the repository's GitHub Pages settings.
- YouTube: https://www.youtube.com/@lucentpsc
- Instagram: https://www.instagram.com/lucent_psc/

This version includes a redesigned responsive homepage, learning sections, social links,
a six-question sample quiz with scoring, and a simple study routine. The quiz is a sample;
it does not yet store student accounts, scores, or examination history.
